# Veterinary Clinic System

ASP.NET Core MVC app for managing vets, pets, and their records.

## What it does

- Manage vets (add, edit, delete)
- Manage pets (assign them to vets)
- Store vet notes (type them in or upload a .txt file)

## Requirements

- .NET 8.0 SDK
- SQL Server (LocalDB works)

## How to run
h
# Restore packages
dotnet restore

# Run it
dotnet runThen go to `http://localhost:5000` in your browser.

Database gets created automatically with some sample data (3 vets, 4 pets, 4 profiles).
